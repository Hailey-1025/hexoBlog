Codewars 新手教學：JavaScript 刷題流程與解題技巧完整解析

發表於 2026-05-10 分類於 Codewars
Codewars 新手教學，完整介紹 JavaScript 刷題流程、kyu 等級制度、題目選擇技巧與解題方法，快速上手程式練習平台。

什麼是 Codewars？

Codewars 是一個以「武術道場」為主題的程式練習平台，每一道題目稱為 kata，完成題目可以獲得積分並提升等級。對於想練習 JavaScript 的人來說，它是非常適合的每日練習工具。

等級制度（kyu）

Codewars 使用日本武術的段位制度來標示難度，數字越小代表越難：

等級 難度 適合對象 實際感受
8 kyu 最簡單 剛學完基礎語法 幾乎是 if / loop 就能解
7 kyu 簡單 了解基本邏輯判斷 開始需要多思考一下
6 kyu 普通 熟悉陣列、字串操作 偶爾會卡關
5 kyu 中等 需要一定演算法概念 明顯感覺難度提升
4 kyu～1 kyu 困難～專家 進階演算法與最佳化 需要扎實的演算法基礎

建議初學者從 8 kyu 開始，循序漸進往上挑戰。

註冊與初始設定

  1. 前往 codewars 點擊 Join 註冊
  2. 如果你有 GitHub 帳號，也可使用 GitHub 帳號直接登入（推薦）
  3. 選擇主要練習語言：選 JavaScript
  4. 完成一道入門驗證題後即可正式使用

主介面說明

登入後會看到 Home 頁面，主要分成左側導覽列與中央內容區。

左側導覽列

按鈕 功能
Home 回到首頁，查看推薦題目
Practice 自選題目練習
Freestyle Sparring 和其他人互相重構彼此的程式碼（進階用）
Leaderboards 全球排行榜
Chat 加入 Discord 社群
Discussions 社群討論題目解法與技巧

基本上新手只會使用到 Home ＆ Practice 就夠了，其他功能可以等熟悉平台後再探索。

選題方式

方式一：隨機選題（訓練模式）

在 Home 頁面的右側有「Training」區塊，點選後進入隨機出題模式：

模式 說明 建議
Fundamentals 基礎題，最適合初學者 ✅ 初學首選
Rank Up 預設模式，系統依照你目前等級推薦較高難度題目 ✅ 一般練習
Practice and Repeat 從已完成的題目中重複練習 ✅ 鞏固熟練度
Beta 尚未審核完成的題目 ⚠️ 暫不建議
Random 完全隨機 看心情

💡 遇到不想做的題目，直接點 SKIP 跳過即可，不影響等級。

方式二：自選題目

點擊左側欄的 Practice 頁面的搜尋框進入題目列表，可使用以下篩選條件：

排序（Sort By）

選項 說明
Popularity 熱門度排序，題目品質有保障 ✅ 推薦
Newest 最新上架
Hardest 最難優先
Most Completed 完成人數最多

排序選項不只上述四項，這邊只列出作者常用的，其他的如果有興趣可以再自行研究

語言（Language）

可以選擇你要練習的程式語言，如果你是要練習 JavaScript 相關的練習題，記得要選擇 JavaScript

狀態篩選（Status）

選項 說明
Approved 經過審核的正式題目 ✅ 推薦
Approved & Beta 正式題目 + 測試中題目
Beta 尚未通過審核的題目，品質參差不齊 ⚠️ 暫不建議

預設為 Approved，保持預設即可，Beta 題目尚未成熟，容易遇到題目描述不清的狀況。

進度篩選（Progress）

選項 說明
All 顯示全部題目（預設）
Kata I have not trained on 從未開啟過的題目
Kata I have not completed 開啟過但尚未完成的題目
Kata I have completed 已完成的題目

新手建議選 Kata I have not trained on，專注挑戰還沒做過的題目。

另外題目旁邊有 ✅ 打勾符號代表你已經完成過囉。

難度篩選（Difficulty）

直接勾選想練習的 kyu 範圍，例如只看 7 kyu 和 8 kyu。

解題介面說明

點進一道題目後，頁面右上角點擊按鈕 TRAIN，即可進入開始解題，解題頁面分為左右兩欄，以 Even or Odd 題目為範例：

左欄：題目描述

頁籤 內容
Instructions 題目說明，包含輸入格式、預期輸出與範例
Output 按下 TEST / ATTEMPT 後的執行結果與錯誤訊息
Past Solutions 你過去寫過的解法紀錄

仔細閱讀這個部分非常重要，確認你理解題目再動手寫。

不要擔心都是英文看不懂，可以先下一個 console 來試跑 Output 的執行結果與訊息，或是用翻譯來幫助理解題目也是沒問題的哦！。

右欄：程式碼編輯區

頁面下方有兩個按鈕：

按鈕 說明
TEST 執行範例 + 部分測試（快速檢查）
ATTEMPT 執行完整測試（用來判斷是否通過）

建議先按 TEST 確認基本邏輯正確，再按 ATTEMPT 正式提交。

恭喜！按完 ATTEMPT 沒問題，就可以 SUBMIT 提交囉！就這樣慢慢賺取分數提高 kata 等級吧！

解題流程建議（建議養成固定習慣）

  • 📌 讀題 — 確認 input / output 格式，不要急著寫
  • 📌 拆解問題 — 把題目改寫成 2～3 個步驟（例如：先排序 → 再過濾 → 再加總）
  • 📌 先寫最直覺的解法 — 不追求完美，先讓它跑起來
  • 📌 TEST 測試小範例 — 驗證基本邏輯
  • 📌 修正邏輯 — 處理邊緣情況（空陣列、負數等）
  • 📌 ATTEMPT 提交 — 跑完整測資
  • 📌 看 Solutions 學優化寫法 — 這步驟最重要，別跳過

新手常見卡關原因

如果你常常覺得「題目看懂了，但不知道怎麼寫」，通常是以下原因：

  • 邏輯沒拆解就直接開始寫 — 先想清楚步驟，再動手
  • 不熟悉 JS 陣列方法 — map、filter、reduce 是高頻工具，幾乎是 7～5 kyu 的核心工具
  • 看懂題目但無法轉成程式 — 試著用中文把解題步驟寫出來，再翻成程式碼
  • 太快看答案 — 卡關前建議先嘗試 20～30 分鐘，如果還沒有方向再參考提示或換題，這段掙扎才是真正的學習

提交後：看他人解法（最重要的步驟）

完成題目後，點選 Solutions 頁籤，可以看到其他人的解法。

這是 Codewars 最有價值的功能之一，特別是看「Clever 解法」，通常可以學到 array / function chaining 的進階寫法。

看完自己的解法後，思考：

  • 有沒有更簡潔的寫法？
  • 別人用了哪些你不熟悉的方法？
  • 解法的可讀性如何？

可以對好的解法按 Best Practice 或 Clever 幫助社群標記優質答案。

⚠️ 不建議一卡關就直接看 Solutions，容易變成「看懂 ≠ 會寫」。先自己努力過，再去參考。

常見初學者問題

Q：題目看不懂英文怎麼辦？
可以搭配翻譯工具，但要注意程式術語不要翻錯，例如 return 就是回傳值，理解錯意思會導致解題方向偏掉。

Q：一直卡關要怎麼辦？
先嘗試 30 分鐘，還是不會的話可以先 SKIP，做其他題目後再回來。也可以參考 Discussions 頁籤中的提示（注意不要直接看答案）。

Q：要每天練習嗎？
有連續練習的天數（Streak）紀錄，但不必強迫自己。建議每天至少完成 1～2 題 8 kyu，養成習慣比一次刷很多題更有效。

小結

目標 建議做法
剛開始練習 選 Fundamentals 模式，從 8 kyu 開始
想找特定類型題目 用 Practice 頁面，Sort by Popularity
想加強弱點 用 Practice and Repeat 複習舊題
想快速提升 每次完成後一定要看 Solutions

Codewars 的精華不只是「寫出來」，更是「看懂更好的寫法」。每次完成題目後花幾分鐘看他人解法，長期下來進步速度會非常明顯。
如果你剛開始刷 Codewars，可以先從 8 kyu 開始每天 1～2 題，重點不是速度，而是理解解題邏輯。
