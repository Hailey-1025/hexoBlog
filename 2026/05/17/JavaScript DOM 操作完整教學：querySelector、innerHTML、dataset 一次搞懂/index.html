JavaScript DOM 操作完整教學：querySelector、innerHTML、dataset 一次搞懂

發表於 2026-05-17 分類於 JavaScript
深入了解 JavaScript DOM 操作的核心概念，包含元素選取、內容修改、屬性設定等常用方法，適合前端開發入門學習。

前言

在 JavaScript 中，DOM 操作幾乎每天都會使用到。像是：

  • 修改按鈕的文字
  • 取得 input 輸入的值
  • 動態新增卡片內容
  • 切換元素的 class 樣式

這些日常開發任務，本質上都是 DOM 操作。

熟悉之後你會發現，DOM 操作其實可以歸納成三大核心分類：

分類 在做什麼 代表方法
選取（Query） 找到目標元素 querySelector、getElementById
改內容（Content） 修改文字或 HTML 結構 textContent、innerHTML
改屬性（Attribute） 設定 HTML 屬性與表單值 setAttribute、dataset、.value

整篇文章的內容都圍繞這三件事展開。

什麼是 DOM？

DOM（Document Object Model，文件物件模型） 是瀏覽器在載入網頁後，自動將 HTML 結構轉換成一棵樹狀結構（DOM Tree），讓開發者能以物件的形式讀取與操作網頁內容。

只要在瀏覽器的開發者工具中輸入 document，就能看到整個 DOM Tree 以物件形式呈現出來。

DOM 載入與 script 執行時機

HTML 是從上到下依序解析的。如果 <script> 在 DOM 節點建立之前就執行，JavaScript 就會找不到目標元素。

現代開發有三種常見的解法：

✅ 方法一：放在 <body> 底部

因為 <script> 標籤會等 HTML 解析到該位置時，才開始下載與執行，所以放在 <body> 底部可確保 DOM 已建立完畢。這是最傳統的做法，簡單直觀。

✅ 方法二：使用 defer

defer 讓瀏覽器在背景下載 script，等整個 DOM 解析完成後才執行。這樣既不阻塞 HTML 解析，也能保證 DOM 準備好，是目前最推薦的寫法。

✅ 方法三：使用 type="module"

ESM 模組預設就有 defer 的行為，同時支援 import / export 語法，適合現代模組化專案。

結論： 新專案優先使用 defer；如果採用模組化架構，使用 type="module"；傳統放 body 底部也可行，只是較舊式。

元素選取方法

querySelector：選取單一元素

querySelector 支援所有 CSS 選擇器語法，只回傳符合條件的第一個元素。

getElementById：以 ID 選取

getElementById 與 querySelector('#text') 結果相同，但效能稍快，適合已知 ID 的情境：

方法 效能 彈性
getElementById 較快 只能用 ID
querySelector 稍慢 支援任意 CSS 選擇器

querySelectorAll：選取多個元素

若要同時取得所有符合的元素，使用 querySelectorAll，它回傳一個 NodeList（節點清單）。

重點比較

方法 回傳值 選取數量

innerHTML 用於讀取或寫入包含 HTML 標籤的內容，寫入時會先清空原有內容，再插入新的 HTML 結構。

⚠️ 進階觀念：innerHTML 的 XSS 安全性風險

innerHTML 會直接將字串解析成 HTML 並執行其中的腳本。攻擊者可能透過惡意字串，在你的網站插入並執行 JavaScript，這種攻擊稱為 XSS（跨站腳本攻擊）。

原則：顯示使用者輸入的內容時，一律用 textContent。

textContent vs innerHTML 選用指南

情境 建議用
純文字顯示 textContent
渲染 HTML 結構（如清單、標籤） innerHTML
內容來自使用者輸入 textContent（避免 XSS）
動態渲染 API 資料 innerHTML（確保資料來源可信）
