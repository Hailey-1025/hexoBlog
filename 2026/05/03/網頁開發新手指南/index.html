網頁開發新手指南

發表於 2026-05-03 分類於 HTML/CSS
HTML 新手入門指南，整理 SEO 必備 Meta Tag（Title、Description、OG）、a 標籤用法與 RWD 基礎技巧，快速建立前端開發基礎。

前言

如果你剛開始學習網頁開發，HTML 的基礎設定可能讓你感到困惑。這篇文章整理了最重要的 HTML 標籤使用技巧，幫助你快速掌握前端開發的核心知識。

語系

<html lang="zh-TW">（完整為 zh-Hant-TW，但大部分瀏覽器會去幫忙做修正）

💡 語系參考文件

meta 標籤

SEO 核心標籤

  • title：

    <title> 是網頁的標題，會顯示在瀏覽器分頁與搜尋結果標題上。

    它不是 meta tag，而是 HTML 文件的標準標籤之一。

    建議長度控制在約 25～30 個中文字內，避免在搜尋結果中被截斷。

  • description：

    Meta description 是用來描述網頁內容的摘要文字，會出現在搜尋結果標題下方，幫助使用者快速理解頁面內容。

    建議長度控制在約 70～120 字之間（中文約 30～60 字），避免在搜尋結果中被截斷。

    ▲ 標題下方的灰色字，就是 Meta description 設定的。

  • Meta og：

    Open Graph（OG）標籤用於社群平台分享時顯示的資訊，例如標題、描述與縮圖。不只 Facebook，LINE、Discord、iMessage 等平台分享連結時也都會讀取 OG 資訊。

    分享時所顯示的縮圖、標題和描述，都是從 meta og 進行設定的。

技術必備標籤

  • Meta charset：

    Meta charset 是瀏覽器顯示網站時採用的字元編碼，是每個網站必要的標籤，現在絕大多數的網站都是採用 utf-8 編碼。

    ⚠️ 忘記設定 charset 會造成亂碼。

  • Meta viewport：

    Meta viewport 用於控制行動裝置上的畫面縮放與寬度，是 RWD 網站的基本設定。

    • width=device-width：畫面寬度等於裝置寬度
    • initial-scale=1.0：初始縮放比例為 1

    ⚠️ 忘記設定 viewport 是新手 RWD 壞掉的第一大原因。

次要 / 已過時標籤

  • Meta keywords：

    Meta keywords 曾經用於描述網頁關鍵字，但現今 Google 已不將其作為排名依據。目前 SEO 不建議依賴此標籤，過度堆疊關鍵字甚至可能被視為低品質內容。

  • Meta robots：

    Meta robots 是給搜尋引擎的「索引指令」，用來控制頁面是否被收錄與追蹤連結。

    ⚠️ Google、Bing 等搜尋引擎通常會遵守 robots 指令，但仍保有最終判斷權，並非強制性規則。

  • Meta copyright：

    用於聲明網頁版權歸屬，例如：<meta name="copyright" content="品牌名稱">。此標籤對 SEO 幾乎沒有影響，主要用於資訊聲明。

📌 SEO 重點整理

標籤名稱 建議長度（中文） 核心作用
Title 25～60 字 網站的門面，直接影響點擊率
Description 30～80 字 摘要網頁內容，吸引使用者進入
OG — 社群平台分享時的預覽資訊（不影響 SEO 排名）
Keywords — Google 已不列入排名，不建議依賴

常見 HTML 標籤補充

前面我們已經介紹了網站的基礎設定（像是 meta 標籤與 SEO 相關內容），接下來會整理幾個「新手最常用、也是實務上一定會用到的 HTML 標籤」。

這些標籤雖然看起來簡單，但幾乎每一個網站都會用到，包含連結、圖片與基本互動行為。

a 標籤

  • target：

    在 a 標籤中加入 target="_blank"，可在新視窗開啟連結。

    使用時機：若希望用戶都在固定網域內行動，則不須加 target="_blank"。

    使用 target="_blank" 時，建議補充 rel="noopener noreferrer"，這是基於資安考量（防止惡意網頁存取原始視窗）。

  • title：

    在 <a> 標籤中加入 title 屬性，可以在滑鼠移上時顯示提示文字（tooltip）。

    ⚠️ 注意：這裡的 title 屬性與 <title>（網頁標題標籤）是不同的東西。

  • 連結顏色（CSS）：

    a 標籤的顏色會受到瀏覽器預設樣式影響（通常是藍色），可透過 CSS 讓它繼承父層顏色：

  • href 屬性變化：

    href 不限於一般網址，可以指向不同類型的連結：

    1. 頁面內錨點

    2. 電話

    3. Email

    4. 簡訊

    5. 檔案下載

      加上 download 屬性後，點擊連結會直接下載檔案而不是開啟它。

<picture> 圖片響應式更換

最常應用在 LOGO 上：

<picture> 會依照條件載入不同圖片，瀏覽器會從上到下比對 <source> 的條件，載入第一個符合的圖片；若全部都不符合，則回退到 <img> 作為預設顯示。

補充：實戰技巧

Layout 概念：

  • 容器：目的在定位，需額外拉出來做定位，原則上不寫高度。
  • 內容：目的在呈現主題，用來撐開容器高度。
  • 裝飾：不影響高度，背景色也是裝飾的一種，需要內容撐開，或直接設定高度。
  • 共用的 class（例如 container），放在自訂 class 後面，例如：<div class="text container">。

圖片行為：

  • img 是 inline replaced element（行內置換元素），雖然表現很像 inline-block（可設定寬高），但本質上仍是 inline。
  • 新手常遇到圖片下方有不明間隙，原因就是 img 是行內元素。建議加上 display: block; 或 vertical-align: middle; 來消除間隙。

開發技巧：

  • Live server 可以利用內網在自己手機上觀看，只要手機跟電腦連同一個網路，把前面的 IP 位置改成自己的區網 IP，就可以用手機連上網頁測試。

  • data-* 屬性：data-自訂名稱="值" 可以在 HTML 元素上埋入自訂資料，搭配 JS 使用非常方便。

結語

HTML 看起來只是一些標籤的組合，但實際上每個標籤都有它對應的「用途與設計目的」。

像是：

  • meta 負責網站資訊與 SEO
  • a 負責連結與互動
  • picture 負責圖片載入策略
  • data-* 則提供前端與 JavaScript 的資料橋樑

當你開始理解「每個標籤為什麼存在」，而不是只是記語法時，HTML 才會真正變得有邏輯。
