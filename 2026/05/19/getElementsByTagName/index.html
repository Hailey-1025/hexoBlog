附注：getElementsByName 還存在嗎？

getElementsByName 目前仍然存在於 DOM 標準中，通常用於取得具有相同 name 屬性的表單元素（例如 radio button 群組）。它並未被移除，但在一般 DOM 操作中較少使用，現代寫法通常以 querySelectorAll("[name='xxx']") 取代。

陣列進階：reduce()

什麼是 reduce()？

reduce() 是陣列的高階方法，對每個元素執行回呼函式並累積結果，最終回傳單一值。

參數 說明
accumulator 累計結果，來自上一次回傳值
currentValue 當前處理的元素
index 當前元素的索引（可選）
array 來源陣列（可選）
initialValue 初始值（強烈建議提供）

若未提供 initialValue 且陣列為空，reduce() 會拋出 TypeError。建議始終提供初始值。

什麼時候該用 reduce()？

reduce() 適合以下場景：

  • 加總 / 計算平均值
  • 統計資料（計算出現次數等）
  • 將陣列轉換為物件或其他結構
  • 扁平化陣列

但注意：如果只是簡單的逐一處理，forEach 的可讀性往往更高。reduce() 的強項在於「需要累積結果」的情境，不應為了「看起來進階」而硬用。
