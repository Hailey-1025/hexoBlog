JavaScript while 迴圈怎麼用？從 0 到理解（附常見錯誤與實例）

發表於 2026-05-08 分類於 JavaScript
JavaScript while 迴圈完整教學，從使用情境、語法說明、常見錯誤到實戰範例，一篇搞懂 while 與 do...while，適合初學者入門

前言

你什麼時候需要 while？

在學習迴圈時，你可能會先接觸到 for，但很快就會遇到一個問題：如果我不知道要執行幾次，該怎麼辦？，例如：

  • 持續讀取資料，直到資料結束
  • 等待使用者輸入正確的值
  • 不斷重試某個動作，直到成功為止

這時候，while 迴圈會是更自然的選擇。

本篇適合 JavaScript 初學者，建議先具備：

  • 變數（let / const）的基本觀念
  • 基本比較運算（<、>、<=、>=、===）
  • 布林值（true / false）的概念

什麼是 while 迴圈？（語法與基本概念）

while 迴圈是一種流程控制結構，用於在條件成立時不斷重複執行某段程式碼。

一句話記住：條件為 true 就繼續跑，條件變 false 就停下來。

while 的本質不是「重複執行」，而是 「持續執行，直到條件不成立為止」

語法

  • 條件：一個會被評估為 true 或 false 的表達式。
  • 程式碼區塊：條件成立時反覆執行的內容。

常見問題與解法

問題 1：無窮迴圈（最常見的錯誤）

如果迴圈內忘記更新條件變數，條件永遠為 true，程式會卡死。

⚠️ 撰寫 while 迴圈時，請先確認：迴圈內是否有讓條件終會變為 false 的邏輯？

問題 2：條件一開始就為 false

若條件在進入迴圈前已為 false，迴圈內的程式碼一次都不會執行。

問題 3：while 與 for 的使用時機

比較項目 while for
適用情境 執行次數不確定，依條件判斷 執行次數固定或已知
典型使用 等待輸入、重試直到成功 跑陣列、固定次數重複

while 不是不能做固定次數的事，但用對工具，程式碼更易讀：

進階用法

break：強制中斷迴圈

當某個條件達成時，用 break 立即跳出迴圈。

continue：跳過當次，繼續下一次

continue 會跳過當次剩餘的程式碼，直接回到條件判斷。

簡單整理：

  • break：直接離開整個迴圈
  • continue：略過這一圈，繼續下一圈

do…while：至少執行一次

do...while 與 while 的差異：先執行，再判斷條件，無論條件為何，程式碼至少執行一次。

適用情境：需要先讓使用者輸入一次，再根據輸入決定是否繼續。

重點整理

概念 說明
while 基本語法 條件為 true 就持續執行，false 就停止
無窮迴圈 迴圈內忘記更新條件變數，最常見的錯誤
while vs for while 適合次數不確定；for 適合次數固定
break 強制中斷並跳出迴圈
continue 跳過當次剩餘程式碼，繼續下一次迴圈
do...while 先執行一次，再判斷條件是否繼續

總結

簡單來說，while 迴圈的核心就是：

👉 「當你不知道要跑幾次，但知道何時停止時，就用 while」

如果還是不確定該用哪個迴圈，可以用這個快速判斷：

  • 次數固定 → 用 for
  • 條件控制 → 用 while

當你開始用「條件」思考，而不是「次數」思考時，你就真的理解 while 了。
