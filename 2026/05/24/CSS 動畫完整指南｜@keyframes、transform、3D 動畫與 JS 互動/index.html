CSS 動畫完整指南｜@keyframes、transform、3D 動畫與 JS 互動

發表於 2026-05-24 分類於 HTML/CSS
深入探討 CSS 動畫核心技巧，包含 @keyframes 設定、3D 透視效果 (Perspective)、JS 動畫事件監聽以及 CSS 變數在主題切換中的實戰應用。

在現代網頁設計中，適當的動畫能提升使用者體驗並增加視覺層次感。本文將從基礎的影格動畫開始，進階到 3D 空間轉換與 JavaScript 的連動控制，協助你紮實掌握 CSS 動畫的核心。

核心動畫概念：@keyframes

重要觀念：同一個元素的 transform 會互相覆蓋，因此多個變形效果必須寫在同一個 transform 中，且 順序會影響結果。

Transform 3D：開啟空間感

要在網頁中呈現 3D 效果，必須先建立「透視感」。

  1. 使用前的必要結構：3D 效果必須由父層定義透視範圍，子層定義 3D 渲染模式。

  2. 常見 3D 屬性

    • translateZ：前後位移（Z 軸）。
    • rotateX / rotateY / rotateZ：繞著不同軸向旋轉，產生 3D 翻轉效果。
    • scaleZ：在 Z 軸方向上的縮放。

參考範例：https://www.casper.tw/WorkShop-gh-pages/css3d/

進階實戰技巧

  1. 運用選擇器與時間差：利用 :nth-child 搭配 transition-delay 可以做出扇形展開或波浪式的動畫效果。

  2. 使用 JavaScript 監聽動畫事件：利用 animationend 事件，可以在動畫徹底結束後執行特定動作（如移除 Class 或轉址）。

  3. 純 CSS 動畫觸發：利用隱藏的 checkbox 與相鄰選取器，可以用純 CSS 製作開關式的動畫（無需 JavaScript）。

CSS 變數應用 (Variables)

以下列範例來說，CSS 變數 (–variable-name) 能極大化程式碼的複用性，它不需要修改 box 的結構，而是用修改變數的方式去更改 box 的背景色跟文字顏色，特別適合用在 深色模式 (Dark Mode) 的切換。

補充：常用屬性速查

✨ pointer-events

控制元素是否響應滑鼠事件（常用於動畫期間禁用互動）

✨ transform-origin

設定變換的中心點（預設為元素中心 50% 50%）

✨ transition-delay

為過渡效果加入延遲時間（常用於製作波浪或序列動畫）
