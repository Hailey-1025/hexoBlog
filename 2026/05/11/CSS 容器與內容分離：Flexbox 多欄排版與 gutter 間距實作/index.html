CSS 容器與內容分離：Flexbox 多欄排版與 gutter 間距實作

發表於 2026-05-11 分類於 HTML/CSS
介紹 CSS 容器與內容分離的設計概念，透過 Flexbox 實作多欄卡片佈局，包含 container、row、column 的職責劃分與 gutter 間距控制技巧。

什麼是容器與內容分離？

許多前端新手在切版時，常會把「排版定位」與「內容樣式」全部寫在同一層元素上，導致元件難以重複使用，也容易在修改版型時互相影響。

因此在實務開發中，通常會將「容器」、「欄位」與「內容」拆分成不同層級，這就是所謂的容器與內容分離。

這種拆分方式能避免樣式互相耦合，提升版型的可維護性與元件重用性。

結構上通常分為三層：

  • 容器（Container）：限制最大寬度、水平置中
  • 欄（Column）：控制寬度比例與欄間距（gutter）
  • 內容（Card / Content）：純粹負責內容樣式，不處理定位

關鍵技巧：負 margin 與 padding 配合實現 gutter

.row 使用負 margin 抵消 .column 的左右 padding，讓第一欄與最後一欄能重新貼齊 .container 的內容邊界，同時維持欄與欄之間固定的 gutter 間距。

補充： .column 加上 box-sizing: border-box 是必要的實務細節。若未設定，padding 會額外增加欄的實際寬度，可能導致換行或 overflow 的問題，這也是許多新手切版時，明明設定三欄卻意外換行的常見原因。。

何時用哪種？ 若需要相容較舊瀏覽器，或與 Bootstrap 等框架整合，使用負 margin 方案；新專案建議優先使用 gap，語義更清晰、程式碼更簡潔。

小結

容器與內容分離的核心概念是讓佈局邏輯不入侵內容樣式。.card 不需要知道自己被放在幾欄的格線中，.column 也不需要知道內部放的是卡片還是其他元件。

Bootstrap 的 Grid System 也是基於類似概念設計：由 container 控制版面範圍、row 負責排列、column 控制欄寬，而內容元件則獨立存在。掌握這個分層思維，是前端切版從「能用」走向「好維護」的關鍵一步。
