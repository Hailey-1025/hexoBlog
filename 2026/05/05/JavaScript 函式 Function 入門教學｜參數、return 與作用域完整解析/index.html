JavaScript 函式 Function 入門教學｜參數、return 與作用域完整解析

發表於 2026-05-05 分類於 JavaScript
JavaScript 函式基礎教學，包含參數、return、作用域與實作範例，適合初學者入門

前言

函式（Function）是 JavaScript 中最重要的基礎概念之一，它能讓我們將重複的程式邏輯封裝起來，提高程式的可讀性與維護性。

在實際開發中，幾乎所有功能（例如按鈕點擊、資料處理、API 請求）都會透過函式來組織，因此理解函式是學好 JavaScript 的關鍵一步。

本篇適合 JavaScript 初學者，建議先具備：

  • 變數（let / const）的基本觀念
  • 基本運算（+、-、% 等）

什麼是函式？

函式（Function）是將一段完整功能的程式碼包裝起來，透過命名後可以重複呼叫使用，避免程式碼重複撰寫。

適合使用函式的時機

  1. 程式碼需要重複使用：相同邏輯出現多次時，改用函式統一管理。
  2. 封裝完整的獨立功能：一段有明確目的的程式，應獨立成一個函式。

命名規則

函式名稱命名規則與變數相同，但應以動詞為主，清楚描述該函式的行為。

動詞前綴 意義
get 取得、取出資料
set 賦予、修改資料
add 增加資料
remove 排除、刪除資料
is 判斷（回傳布林值）
do 執行某段邏輯
check 檢查、驗證
calc 計算

函式內呼叫其他函式

函式內可以再呼叫其他函式，程式會先執行被呼叫的函式，完成後才繼續往下執行。

參數（Parameter）

參數是函式與外部環境溝通的管道，就像變數一樣，可以將值傳入函式中使用。

⚠️ 參數只存活於函式的大括號內，離開函式後即無效。

return 回傳值

一句話記住：return = 「把結果帶出去 + 停止函式執行」

當需要將計算結果拿到函式外部使用時，必須透過 return 回傳。

return 執行後，函式立即結束，其後的程式碼不會再執行。

全域變數與區域變數

函式內若找不到某個變數，會向外層作用域查找，這個機制稱為 Scope Chain（作用域鏈）。

⚠️ 若需要跨次呼叫保存資料，可以使用外部變數，但實務上更建議使用 closure（閉包）或物件封裝，避免污染全域變數。

全域變數在大型專案中容易造成「不可預期的修改來源」，是常見的 Bug 來源，也是面試常問觀念之一。

重點整理

概念 說明
函式宣告 function 名稱(參數) { ... }

結語

函式是 JavaScript 中最核心的基礎之一，從最簡單的「重複執行程式碼」，到進階的「狀態管理、閉包與模組化設計」，都建立在函式之上。

本篇我們學到了：

  • 函式的基本寫法與呼叫方式
  • 參數如何傳遞資料
  • return 如何回傳結果並中斷函式
  • 全域變數與區域變數的差異與風險
  • 基本的實際應用範例

如果你能理解這些概念，代表你已經具備 JavaScript 入門到進階的關鍵基礎。

接下來建議可以往以下方向延伸學習：

  • Arrow Function（箭頭函式）
  • Callback Function（回呼函式）
  • Closure（閉包）
  • Hoisting（提升）

這些會讓你開始真正理解「JavaScript 的運作方式」，而不只是語法本身。
