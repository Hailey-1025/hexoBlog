視差滾動教學｜Parallax.js、Lax.js 與 CSS background-attachment 實作

發表於 2026-05-30 分類於 HTML/CSS
視差滾動實作教學介紹 Parallax.js、Lax.js 套件與 CSS background-attachment 三種方法，附實際範例與程式碼。讓網頁動起來就是這麼簡單！

前言

視差效果（Parallax）是網頁設計中常見的視覺技巧，透過讓不同圖層以不同速度移動，創造出立體感與空間感。

雖然常見於滾動動畫（Parallax Scrolling），但也能搭配滑鼠移動或裝置感應來實現互動效果。

本文將介紹三種實作方式：適合滑鼠互動的 Parallax.js、純 CSS 的 background-attachment 技巧，以及功能強大的 Lax.js 滾動動畫庫。無論你是初學者還是想精進技術，都能找到適合的解決方案。

⚙️ 核心屬性說明

屬性 功能說明 範例值
data-calibrate 是否根據初始 x 軸位置計算運動量 true/false
data-invert 是否反向運動 true/false
data-limit 限制 x 或 y 方向的最大運動範圍 10, 50 等數字
data-scalar 運動靈敏度(數值越大越靈敏) 2, 8, 20 等
data-friction 運動摩擦力(0-1 之間) 0.2, 0.8 等

其他推薦套件

如果上述方案不符合需求，還有這些選擇：

  • ScrollMe - 輕量級滾動動畫
  • jQuery Parallax Plugins 合集 - 12 種不同風格的視差套件

選擇建議

  • 初學者/簡單需求： 使用純 CSS background-attachment: fixed
  • 需要滑鼠互動： 選擇 Parallax.js
  • 複雜滾動動畫： Lax.js 最適合
  • 專案已使用 jQuery： jQuery 版本整合更順暢

⚠️ 效能提醒：行動裝置要特別注意視差效果的流暢度，建議使用 will-change 或考慮在小螢幕停用視差效果。
