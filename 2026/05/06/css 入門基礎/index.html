CSS 權重規則

選擇器 權重 範例 建議
HTML 標籤 1 p { } 全域基礎樣式
class 10 .box { } 主要使用
id 100 #header { } 避免用於樣式
inline 1000 style="..." 盡量避免，維護性差且可能影響 CSP 安全政策
!important 10000 !important 權重最高，盡量避免

重點：

  • 先看權重，權重相同才看順序（後寫覆蓋先寫）

  • 權重是位數比較，不是數量累加：

    • id：0,1,0,0
    • class：0,0,1,0

    因此再多的 class 也不會超過一個 id。

  • 原則上只寫在 class，一個網頁的 id 只會出現一個，樣式永遠不要使用 id

文字樣式

🌟 字體設定

原則：

  • 先英文後中文，最後放通用字型（sans-serif）
  • 字體名稱建議使用英文，或中英都放
  • 名稱有空格要加引號，例如：”Apple Color Emoji”
  • 通常撰寫字型的時候會在最後將通用字型（像是：sans-serif 無襯線字體）寫上，確保各個裝置都能正確瀏覽
  • 若是 Google Fonts 沒有的字型，可以看是否能下載到本地放入專案資料夾中使用 @font-face 載入，或是和設計師討論使用 Google Fonts 雲端字型

🌟 字型單位

瀏覽器預設：16px = 100% = 1em

rem 單位

rem 的尺寸是使用最外層 html 或 :root 設定的文字大小去做計算，不受 body 影響，故內層的 strong 尺寸依然是 32px，不會受到上一層的影響。請注意，若是用 body 去設定文字大小，rem 吃的依然是 html 的 16px，rem 使用上相對比 em 還要穩定許多。

🌟 常用屬性

  1. font-family: verdana;（字型：電腦預設字型）

    💡 中文字體有包含英數，但英文字體只有英數，如果要中英不同字體，可將英文字體放在前面。參考：@font-face

  2. font-size: 16px;（如不設定，網頁預設即為 16px，此處僅為示範）
  3. line-height: 1.5;（行高，建議無單位，此設定為 1.5 倍 × 字體大小 16px = 1 行 24px 高度）

    💡 font-size 是靠行距撐出高度，預設是 100%，若行距為 0，font 本身文字無法顯現，故實際元素高度會受到 line-height 影響，行距會影響文字區塊的整體高度呈現。

  4. font-weight: 700;（粗體，建議用數字，瀏覽器的支援會比較好）
  5. letter-spacing: 0.5px;（字距）
  6. text-align: center;（對齊）
  7. text-indent: 2em;（首行縮排）
  8. vertical-align: middle;（垂直對齊）
  9. text-decoration: underline / line-through;（裝飾線：下底線／刪除線）

間距管理

三層級觀察法：

  • 大區塊：section 之間（80-120px）
  • 中區塊：內容區塊（40-60px）
  • 小區塊：元素之間（16-32px）

原則：統一推擠方向，例如統一使用 margin-bottom 與 margin-right，比起穿插 mt、mr、ml、mb，未來會更容易維護。

Container 容器

🌟 使用 container 限縮內容寬度

為什麼要使用 container：

  • 人的視線會集中在畫面中央
  • 網頁中非滿版、置中的排版可直接套用

如何在設計稿找出 container 寬度：

  1. 看設計稿 Guideline
  2. 格線計算
  3. 找最寬的非滿版元素

💡 注意：設計稿的 1920px 代表滿版，所以切版時，最外圍「不需要」設定 1920px，另外 container 通常會搭配 RWD 斷點設定不同的 max-width

元素置中、置右

  • 元素預設會置左排列，通常不用另外設定
  • margin: 0 auto
    • 區塊元素
    • 有設定 max-width
  • text-align
    • 區塊元素
    • 作用在內部的內容

盒模型

兩種模式：

  • content-box（預設）：width 不含 padding/border，會累加
  • border-box（推薦）：width 包含 padding/border，自動扣除

Flexbox 是目前最主流的一維排版方式，適合做導覽列、卡片列表、垂直置中等。

常用屬性速查：

屬性 說明 常用值

align-items 交叉軸（垂直）對齊 flex-start / center / stretch
flex-wrap 是否換行 nowrap（預設）/ wrap
flex-direction 排列方向 row（預設）/ column
gap 子元素間距 px 或 rem
align-content 多行時的交叉軸對齊 center / space-between

🌟 Grid（進階）

Grid 是二維排版，適合整頁佈局、複雜的欄列結構。

💡 Flexbox 管「一行」的排列，Grid 管「整個版面」的欄列結構，兩者可以搭配使用。

CSS Reset

方案 特點
Meyer’s Reset 完全清空所有預設樣式
Normalize.css 讓不同瀏覽器預設樣式趨於一致，保留有用樣式（推薦）
Bootstrap Reboot 基於 Normalize + BS 規範

Normalize.css 不會清空所有樣式，而是讓各瀏覽器的預設樣式更一致；Meyer’s Reset 則是全部清空。Normalize 與 Bootstrap Reboot 相似，設計師較常用，但用哪一套 Reset 一樣要看設計師需求。

💡 注意：使用 Bootstrap 或 Tailwind 就不需額外載入 Reset，因為這些框架本身已經內建 Reset（或 Normalize）機制

響應式設計

🌟 主流斷點

如何決定斷點：

  • 斷點會隨著市場裝置的使用率而有所改變，可參考主流 CSS 框架的斷點設定，例如 Bootstrap、Tailwind
  • 一開始只需要針對熱門斷點做設定就好，不可能做到所有裝置呈現都很完美，先滿足 80% 裝置的需求即可

常用斷點：

  • 992px：平板（768px~992px 是小螢幕平板範圍）
  • 768px：適合元素較多的內容轉為手機版
  • 576px：較常見的手機版斷點

🌟 實戰範例

注意事項：

  1. 媒體查詢也有權重順序，max-width 要從大 → 小，min-width 要從小 → 大
  2. 避免在常見裝置寬度（如 375px）出現橫向捲軸（overflow-x）
  3. 斷點不超過 5 個
  4. 手機版手指點選的目標高度建議至少 44px，使用者體驗才會比較好
  5. 圖片與影片建議設定 max-width: 100%，避免超出容器

樣式管理

樣式應該寫在 class 還是標籤上：

  • 如果設計稿裡面，該標籤樣式都相同，就可以直接設定在標籤上，例如 a 標籤
  • 一般建議樣式都設定在 class 裡
  • 建議 class 命名語意化，有助於後續維護，保證自己幾個月後還是看得懂，也有助於團隊協作
  • 避免將樣式過度依賴 HTML 結構（例如 .header ul li a），會降低重用性

新手常見錯誤

  • 用 id 寫樣式（權重過高、難以覆蓋）
  • 濫用 !important（掩蓋問題而非解決問題）
  • 過度巢狀選擇器（.a .b .c .d，維護困難）
  • 用 px 寫死所有尺寸（不利響應式）
  • 沒有設定 box-sizing: border-box（造成寬度計算錯誤）

實戰技巧

  • 用 outline: 1px solid red; 快速查看排版
  • 圖片加 vertical-align: middle; 移除底部 3px 留白
  • 全域設定一般行高為 1.5，標題一般為 1.2
  • 避免直接設定標籤樣式（除非全站統一）
  • 使用瀏覽器開發者工具查看元素尺寸和總高度
  • 針對該網站進行全站 Base 樣式重構與客製化
  • 可以重複 class 來覆蓋 class 樣式，這種方式中間不需要加入空白鍵（僅作為理解權重用途，不建議實務使用）

Figma 快捷鍵：

  • Cmd + 點擊：選取最內層元素
  • Shift + G：開關格線
  • Alt + 移到元素：查看間距

總結

CSS 看似簡單，但真正困難的是「如何管理樣式與維護」。本篇帶你建立 CSS 的核心觀念：

  • 權重與選擇器邏輯
  • 文字排版與間距
  • 盒模型與 Flexbox / Grid 版面
  • 響應式設計

當你能把樣式寫得「穩定、可維護」，就已經超越多數初學者了。
