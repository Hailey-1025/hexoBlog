搞懂 CSS Transition、Transform 與 Animation 差異｜網頁動態效果完整指南

發表於 2026-05-27 分類於 HTML/CSS
從零開始學 CSS 動態效果！本篇完整介紹 Transition、Transform 2D 轉換、Animation 關鍵影格與 AOS 套件，附實際範例與常見地雷解析，讓你的網頁動起來！

網頁會動，才有靈魂。這篇文章會帶你從最基礎的 transition 到進階的 animation，一次搞懂讓網頁「活起來」的三個核心武器 🎯

為什麼要學 CSS 動態效果？

你有沒有遇過這種情況：滑鼠移到按鈕上，顏色瞬間切換，感覺很生硬？或者想讓圖片 hover 時稍微放大一點、有個滑順的過渡感？

這些都可以靠 CSS 原生功能解決，不需要 JavaScript，效能又好。這篇文章會介紹三個主角：

  • Transition：讓樣式變化變得「滑順」
  • Transform：讓元素移動、縮放、旋轉
  • Animation：自訂關鍵影格，做出複雜動畫

還有一個超好用的動畫套件 AOS，滾動時觸發動畫，幾乎是每個靜態網站的標配！

一、Transition

📖 MDN 官方文件

Transition 的功用很單純：當 CSS 屬性從 A 變成 B 的時候，讓這個「變化過程」有動畫感，而不是瞬間跳變。

核心屬性

屬性 說明 範例值
transition-property 要套用動畫的 CSS 屬性 background, width, all
transition-duration 動畫持續時間 0.3s, 500ms
transition-timing-function 速度曲線 ease, linear, ease-in-out
transition-delay 延遲幾秒才開始 0s, 0.2s

實際範例：Hover 顏色切換

💡 常見地雷：很多新手會把 transition 寫在 :hover 裡面，這樣只有「進入」有動畫，「離開」會直接跳回去，一定要寫在原始 class！

時間建議

動畫時間不是越長越好，一般 UI 互動建議：

  • Hover 效果：0.2s ~ 0.3s（太長會覺得網站很慢）
  • 展開收合、卡片翻轉：0.3s ~ 0.5s
  • 頁面切換動畫：0.5s 以內

二、Transform：移動、縮放、旋轉

📖 MDN 官方文件

Transform 讓你可以在不影響頁面排版的情況下，改變元素的視覺位置與形狀。

常用的 Transform 值

⚠️ 超級重要： 同一個 class 裡只能有一個 transform 屬性，後面的會蓋掉前面的！要組合多個效果，請寫在同一行。

Transform 的特性整理

Transform 有幾個很重要的特性，弄懂之後才不會被搞混：

1. 不影響原始排版
元素移動後，原本的「空位」還是保留著。這跟 margin、position 不一樣，比較適合做「視覺裝飾」而非真正的位置調整。

2. 以自身中心為基準
旋轉、縮放都是以元素自己的中心點出發，不是從容器的左上角。如果要改變基準點，可以用 transform-origin。

3. 自動啟用硬體加速
這是 transform 最大的優點！瀏覽器會把 transform 交給 GPU 處理，效能比 top/left/margin 好非常多，適合用在頻繁的動畫效果。

Opacity 簡單但非常實用，常用來做淡入淡出效果。

四、Animation：關鍵影格動畫

📖 MDN 官方文件

Transition 只能處理「從 A 到 B」的變化，但如果你想做多個步驟的動畫（像 loading 轉圈、文字跑馬燈），就需要 Animation + @keyframes。

基本結構

Animation 分兩個部分：

  1. @keyframes：定義動畫的各個階段
  2. animation 屬性：指定哪個元素要套用、持續多久等等

影格概念：

Animation 完整屬性一覽

屬性 說明 常用值
animation-name ⭐ 對應 @keyframes 名稱 自訂名稱
animation-duration ⭐ 一次動畫的時間 1s, 500ms
animation-timing-function 速度曲線 ease, linear, cubic-bezier()
animation-delay 延遲幾秒開始 0s, 0.5s
animation-iteration-count 播放幾次 1, 3, infinite
animation-direction 播放方向 normal, reverse, alternate
animation-fill-mode 動畫結束後的狀態 forwards（保持最後狀態）
animation-play-state 暫停或播放 running, paused

💡 animation-fill-mode: forwards 是很常忘記的屬性，如果你發現動畫結束後元素跳回原本的樣子，加上這個就對了！

簡寫格式

效能小提醒

盡量用 transform 和 opacity 來做動畫，避免直接動 top、left、width、height，因為後者會觸發瀏覽器重新排版（Reflow），效能差很多。

AOS 常用屬性

屬性 說明 範例值
data-aos 動畫效果名稱 fade-up, zoom-in, flip-left
data-aos-duration 持續時間（毫秒） 400（預設）, 800
data-aos-delay 延遲（毫秒） 0, 200, 400
data-aos-easing 速度曲線 ease, ease-in-out
data-aos-once 只播放一次？ true / false
data-aos-mirror 離開視窗時反向播放？ true / false
data-aos-offset 觸發點偏移（像素） 120（預設）
data-aos-anchor-placement 觸發時機 top-bottom, center-bottom

⚠️ Duration 超過 1000ms 的話，使用者可能會覺得你的網站很慢，請謹慎使用！
