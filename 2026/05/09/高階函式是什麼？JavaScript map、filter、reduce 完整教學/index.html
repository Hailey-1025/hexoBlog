高階函式是什麼？JavaScript map、filter、reduce 完整教學

發表於 2026-05-09 分類於 JavaScript
深入理解高階函式的概念與實際應用，從 map、filter、reduce 到自訂高階函式，帶你寫出更簡潔、更具表達力的程式碼。

前言

在學 JavaScript 時，你可能已經寫過很多 for 迴圈：

  • 跑陣列
  • 篩選資料
  • 做加總

但你有沒有想過，其實這些操作都有更簡潔、更好讀的寫法？

這就是高階函式登場的地方。

這篇文章會帶你從最常見的 map、filter、reduce 開始，一步步理解什麼是高階函式，以及它為什麼能讓你的程式碼變得更乾淨、更好維護。

什麼是高階函式？

簡單來說，高階函式是符合以下至少一個條件的函式：

  1. 接受函式作為參數
  2. 回傳一個函式

這聽起來有點抽象，但其實你每天都在使用它。Array.prototype.map、filter、reduce——這些全都是高階函式。

為什麼 JavaScript 可以做到這件事？

因為在 JavaScript 中，函式是一等公民（First-class citizen）：

  • 可以被當作變數
  • 可以傳入函式
  • 可以被回傳

這也是高階函式成立的基礎。

三大常用高階函式

map — 轉換每個元素

map 會對陣列中的每個元素套用你提供的函式，並回傳一個新陣列。

重點：map 不修改原陣列，它永遠回傳新陣列。

filter — 篩選符合條件的元素

filter 接受一個判斷函式（predicate），只保留讓函式回傳 true 的元素。

reduce — 將陣列「折疊」成單一值

reduce 是最強大也最靈活的高階函式。它將陣列逐步「累積」成單一結果。

你可以把 accumulator 想成「目前累積的結果」，current 則是「現在處理的元素」。每跑一次，就把結果更新一次。

reduce 的第二個參數是初始值，強烈建議總是明確傳入，避免意外行為。

總結

函式 用途 回傳值
map 轉換每個元素 新陣列（長度相同）
filter 篩選元素 新陣列（長度 ≤ 原陣列）

高階函式讓你的程式碼：

  • ✅ 更短、更少樣板程式碼
  • ✅ 更易讀、意圖清晰
  • ✅ 更好測試、因為函式是純粹的
  • ✅ 更容易組合與重用
