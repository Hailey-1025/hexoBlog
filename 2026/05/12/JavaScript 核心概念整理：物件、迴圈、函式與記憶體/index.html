JavaScript 核心概念整理：物件、迴圈、函式、拷貝與記憶體

發表於 2026-05-12 分類於 JavaScript
整理 JavaScript 中常見的核心概念，包含 switch、物件操作、迴圈、拷貝、函式陳述式與表達式、一級函式，以及基本型別與物件型別的傳遞差異。

前言

JavaScript 在學習初期，常常會同時接觸到很多看似零散的概念，例如：

  • switch
  • 物件（Object）
  • 迴圈（Loop）
  • 淺層拷貝與深層拷貝
  • 函式陳述式與函式表達式
  • 傳值與記憶體參考

剛開始學時，很容易變成「每個都看過，但不知道彼此有什麼關聯」。

這篇文章整理了 JavaScript 中幾個常見且重要的核心觀念，內容以初學者角度出發，搭配簡單範例說明，幫助你建立對物件、函式、迴圈與記憶體運作的基本理解。

switch 條件判斷

switch 是處理多條件判斷的語法，功能類似多個 if...else if。

範例中若只是輸出內容，通常使用 break 即可；return 多半用在函式需要提前結束並回傳值時。

注意：不用 return 時要加 break

switch 的特性是：只要進入一個 case，如果沒有 return 或 break 中斷，會繼續往下執行所有 case（稱為「fall-through」）。

物件拷貝

淺層拷貝

只複製第一層屬性。若物件內有巢狀陣列或物件，仍然共用同一個記憶體參考。

使用物件字面值 {} 或陣列字面值 [] 時，通常會建立新的參考型別資料。

深層拷貝

完整複製所有層級，但 structuredClone() 無法處理 function、DOM 節點等特殊資料型別。

何時用哪種？

  • 物件結構單純、或需要保留函式 → 用淺層拷貝
  • 有複雜的巢狀資料需要完整隔離 → 用深層拷貝

const 與 let 的使用原則

沒有重新賦值的需求，就應該使用 const。只要不會出錯，預設用 const。

一級函式（First-Class Functions）

JavaScript 中，函式是「值」的一種，可以像變數一樣被操作，稱為一級函式。

一級函式 vs 高階函式

概念 說明
一級函式 語言特性，函式可像值一樣被賦值、傳遞、回傳
高階函式 使用技巧，指接收函式為參數、或回傳函式的函式

基本型別與物件型別的傳遞差異

基本型別：傳遞值的副本

適用於：number、string、boolean、null、undefined 等。

物件型別：傳遞記憶體位址的副本

適用於：Object、Array、Function。

JavaScript 實際上都是「傳值（pass by value）」；只是物件型別的值是記憶體位址（reference），因此修改屬性時會影響原物件。

重要陷阱：換掉整個物件不會影響外部

總結

情況 會影響外部？ 說明
傳基本型別（數字、字串） ❌ 不會 傳的是值的副本
傳物件 / 陣列，修改屬性 ✅ 會 傳遞的是 reference 的副本
傳物件 / 陣列，換掉整個物件 ❌ 不會 只改了參數指向，原變數不變

以上這些觀念，幾乎都是 JavaScript 開發中最常接觸的基礎內容。

剛開始學習時，可能會覺得：

  • 名詞很多
  • 行為很像
  • 容易混淆

但其實這些概念彼此之間都有關聯。

例如：

  • 函式其實也是物件的一種
  • 淺拷貝與深拷貝牽涉到記憶體參考
  • forEach 能接收函式，和一級函式的概念有關
  • 物件型別的傳遞方式，也會影響資料是否被改動

比起一次硬背所有名詞，更重要的是：

能理解「為什麼會這樣運作」。

當你開始實際撰寫專案、操作資料與除錯時，這些觀念會慢慢串起來，也會越來越熟悉。
