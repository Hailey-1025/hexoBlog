JavaScript 比較與邏輯運算子完整指南｜if else 與三元運算子一次搞懂

發表於 2026-05-22 分類於 JavaScript
一次搞懂 JavaScript 的比較運算子（==、===）、邏輯運算子（&&、||、!）、if/else 條件式與三元運算子！附大量生活情境範例，以及 Truthy / Falsy、短路求值等實戰觀念。

條件判斷是程式的靈魂——沒有它，程式就只會從頭跑到尾，什麼決定都做不了。這篇文章從比較運算子、邏輯運算子到 if/else，再到三元運算子與實戰常用的 Truthy/Falsy 觀念，一路帶你搞懂 JavaScript 的判斷邏輯

比較運算子

比較運算子用來比較兩個值，結果一定是布林值（true 或 false）。

運算子 意義 範例 結果
> 大於 5 > 3 true
< 小於 2 < 1 false
>= 大於等於 3 >= 3 true
<= 小於等於 4 <= 5 true
== 等於（會自動轉型） 1 == '1' true
=== 嚴格等於（型別也比） 1 === '1' false
!= 不等於（會轉型） 1 != '2' true
!== 嚴格不等於 1 !== '1' true

所有條件都要成立，才回傳 true。

補充一：Truthy / Falsy

JS 在做條件判斷時，不是只看「true 或 false」，而是把所有值分成「真值（Truthy）」和「假值（Falsy）」。

其他所有值（包含空陣列 []、空物件 {}）都是 Truthy，會被當成 true。

理解這個概念，才能真正看懂 || 和 && 的進階行為。

補充二：邏輯運算子的回傳值 + 短路求值（Short-circuit Evaluation）

邏輯運算子在判斷時會把值轉為布林，但實際回傳的是「原本的值」，不是 true/false。

這種「左邊已經能決定整體結果，就不繼續執行右邊」的行為，有個專有名詞叫做短路求值（Short-circuit Evaluation）。面試和 React 程式碼裡都很常見。

總結

條件判斷是 JavaScript 的骨幹，但它通常不會單獨出現，而是跟以下這些概念一起使用：

  • switch：多條件分支的另一種寫法，某些情境比 if/else if 更清晰
  • for / while 迴圈：重複執行某段邏輯時，裡面幾乎都會搭配條件判斷
  • 陣列方法（map、filter、reduce）：filter 本身就是一個「幫你跑條件判斷」的工具
  • Expression vs Statement、函式表達式

每學完一個，都會讓你對條件判斷的理解又更深一層
