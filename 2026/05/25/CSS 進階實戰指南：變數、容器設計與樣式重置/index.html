外層容器設計模式

良好的容器設計是響應式佈局的基礎。

Container 容器的核心概念

.container 通常代表外層容器，負責：

  • 設定最大寬度（max-width）
  • 水平置中（margin: 0 auto）
  • 左右留白（padding）

為什麼要設定左右 padding？
在小螢幕裝置上，如果沒有 padding，內容會緊貼視窗邊緣，影響閱讀體驗。

為什麼使用百分比寬度？

使用 calc(50% - 12px) 的原因：

  • 彈性佈局：適應不同容器寬度
  • 間距計算：兩欄之間存在 24px 的 gap，每張卡片需各扣除 12px，避免總寬度超出容器
  • 響應式友善：容易調整為單欄或三欄佈局

現代方案：使用 gap 屬性
