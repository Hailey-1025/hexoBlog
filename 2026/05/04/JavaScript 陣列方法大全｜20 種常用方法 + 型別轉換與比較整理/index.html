前言

在學習 JavaScript 時，陣列與物件操作是最常見但也最容易混淆的部分。

例如：

  • map、filter、reduce 看過，但用不順

JSON 格式介紹

JSON（JavaScript Object Notation）是一種輕量級的資料交換格式，幾乎所有後端 API 回傳的資料都是這個格式。

JSON 跟 JS 物件的差異：

  • JSON 的屬性名稱一定要用雙引號包起來
  • JSON 不能有函式、不能有 undefined
  • 字串值也必須用雙引號

JSON 是「資料格式」，Object 是「程式結構」

總結

真正的重點不是記住所有方法，而是理解：

  • 分清 mutation vs immutable（改沒改原陣列）
  • 熟 map / filter / reduce，這三個最常用
  • 永遠用 ===，== 的轉型規則記不完
