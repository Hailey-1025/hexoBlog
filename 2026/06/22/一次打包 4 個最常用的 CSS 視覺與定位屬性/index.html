一次打包 4 個最常用的 CSS 視覺與定位屬性

發表於 2026-06-22 分類於 HTML/CSS
CSS 視覺與定位完整指南！深入解析 Border 邊框、Position 定位系統（relative/absolute/fixed/sticky）、Overflow 溢出處理、Object-fit 圖片適應四大核心屬性，搭配實戰範例與應用場景，讓你快速掌握網頁排版技巧。

前言

在前端開發中，視覺呈現和元素定位是構建使用者介面的兩大核心技能。本文將介紹 border、position、overflow 與 object-fit 四個常用屬性，並透過實際應用場景幫助你掌握這些屬性的使用時機與技巧。

Border - 邊框屬性

🌟 基本語法

💡 重點提醒
border 簡寫通常包含寬度、樣式與顏色，其中 border-style 是必要條件，缺少時可能不會顯示。

🌟 線條樣式類型

透明邊框的應用場景：

  • 保持元素盒模型尺寸一致（避免 hover 時因新增邊框而位移）
  • 搭配 border-image 製作漸層邊框效果

🌟 單邊邊框控制

實務應用：

  • 標籤/分類標示：用底部邊框標示 active 狀態的 tab
  • 視覺分隔：左右邊框作為側邊欄分隔線
  • 強調設計：頂部粗邊框作為卡片或區塊的設計重點

🌟 進階技巧：邊框圓角與陰影

Position - 定位系統

CSS 定位系統是控制元素在頁面中位置的關鍵機制。理解不同定位類型的差異，能讓你精準控制版面佈局。

🌟 定位類型概覽

類型 特性 常見用途
static 預設值，按正常文檔流排列 一般內容
relative 相對於原始位置偏移 作為絕對定位的父容器
absolute 最近一個 position !== static 的祖先元素，若沒有則以 viewport 或 initial containing block 為準 浮動元素、彈出視窗
fixed 相對於視窗固定 固定導航列、回到頂部按鈕
sticky 滾動到特定位置後固定 黏性表頭、側邊欄

🌟 Relative + Absolute 父子定位

這是最常見的定位組合，用於精確控制子元素位置。

💡 核心概念
absolute 定位的元素會脫離正常文檔流，不佔據空間。它會尋找最近的 position 不為 static 的祖先元素作為定位參考點。

🌟 Z-Index 圖層控制

⚠️ 注意事項
z-index 通常只對已定位元素（position 不為 static）生效，但在 flex / grid 等情境下也可能影響堆疊層級

🌟 Fixed 固定定位

實務應用：

  • 購物車圖示
  • 聊天客服按鈕
  • Cookie 同意橫幅
  • 固定側邊欄

🌟 Sticky 黏性定位

Sticky 與 Fixed 的差異：

  • sticky 在滾動前按正常流排列，滾動到指定位置後才固定（例如 nav 導覽列）
  • fixed 始終相對於視窗固定，並且將某物固定在某個區塊，不受頁面滑動的影響

Object-fit - 圖片適應

當使用 <img> 標籤並固定寬高時，object-fit 能控制圖片如何適應容器，避免變形或裁切不當。

背景圖片的部分可參考之前的文章 background-img

🌟 屬性值詳解

🌟 各屬性值比較

1. fill（預設值）

  • 效果：拉伸圖片以填滿整個容器
  • 缺點：可能造成圖片變形
  • 適用：不在意圖片比例的裝飾性圖片

2. contain

  • 效果：保持比例，完整顯示圖片，可能留白
  • 適用：產品圖、LOGO、需完整顯示的圖片

3. cover

  • 效果：保持比例，填滿容器，可能裁切部分內容
  • 適用：背景圖、卡片縮圖、頭像

4. none

  • 效果：保持原始尺寸，不縮放
  • 適用：圖標、小型裝飾圖

5. scale-down

  • 效果：取 none 或 contain 中較小的顯示尺寸
  • 適用：響應式圖片處理
