JavaScript 陣列方法完整指南｜push、splice、map、filter、reduce 一次搞懂

發表於 2026-06-09 分類於 JavaScript
完整介紹 JavaScript 最常用的陣列操作方法，包含 push、pop、splice、map、filter、reduce 等，並附上實際情境範例與速查表，新手入門必讀！

陣列是 JavaScript 裡最常用的資料結構，幾乎每個功能都會碰到它。這篇文章把常用的陣列操作方法整理在一起，書籤起來當參考手冊就對了 📌

先搞懂一件事：會不會動到原陣列？

陣列方法可以分成兩大類，搞清楚這件事能避免很多意料外的 bug：

  • 🔧 會改變原陣列（mutating）：push、pop、splice、sort、reverse…
  • ✨ 不會直接改變原陣列（non-mutating，回傳新陣列）：map、filter、reduce、slice、concat…

後者會回傳一個全新的陣列，原始資料完全不受影響。

💡 注意：JavaScript 本身並沒有真正「不可變的陣列」，除非你使用 Object.freeze() 或 Immutable.js 等工具。這裡說的「不改變原陣列」，指的是這些方法不會 mutate 原始資料。

splice：精準刪除或插入指定位置

splice 是最靈活的陣列方法，可以刪除、新增、甚至替換，全靠參數控制。

⚠️ 第二個參數如果不填，會從起始位置一路刪到最後。常見 bug：第二個參數沒控制好，會導致大量資料意外被刪除，務必小心！

sort：排序

⚠️ sort() 是「就地排序」（in-place），會直接修改原陣列。如果要保留原始順序，記得先複製一份：[...nums].sort((a, b) => a - b)。這也是面試和實務都很常考的坑。

map：轉換每個元素，回傳新陣列

forEach vs map 的關鍵差異：

  • map 會回傳新陣列，可以繼續鏈式處理（chain）
  • forEach 不回傳任何值，也無法鏈式處理

需要「轉換資料」就用 map，只是「執行動作（如印出、更新 DOM）」就用 forEach。
