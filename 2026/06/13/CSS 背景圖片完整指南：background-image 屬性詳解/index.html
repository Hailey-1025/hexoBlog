CSS 背景圖片完整指南：background-image 屬性詳解

在網頁開發中，背景圖片是營造視覺效果的重要元素。本文將帶你深入了解 CSS 的 background-image 屬性，以及相關的背景控制屬性，讓你能靈活運用背景圖片打造精美的網頁設計。

contain 會在維持圖片比例的前提下縮放圖片，並確保整張圖片完整顯示於容器中，因此容器可能出現留白；cover 則會維持比例縮放並填滿整個容器，部分圖片可能被裁切。

background-repeat

background-image 預設會重複平鋪（repeat），若只希望顯示一次，可透過 background-repeat 設定。

repeat(預設值)｜ repeat-x ｜ repeat-y ｜ no-repeat

size/position/repeat 比較

屬性 常用值 效果說明 建議使用情境
background-size cover 等比例縮放圖片，直到填滿容器（邊緣可能會被裁切） 全螢幕 Banner、大標題背景
– contain 等比例縮放圖片，確保完整顯示（容器可能會有留白） 顯示完整 Logo、產品插圖
background-position center 將圖片對齊容器的中心點 讓背景主題維持在視覺中央
– top / bottom 將圖片對齊容器的頂部或底部 保留人物頭部或特定的底部裝飾
background-repeat no-repeat 圖片只顯示一次，不重複 單一背景大圖的首選
– repeat-x / y 僅在水平或垂直方向重複圖片 條紋底紋、重複性背景圖案

圖片取代文字內容

  • 搜尋引擎認識 h1 與內容，但不認識圖片，故文字仍保留，於 CSS 隱藏，使頁面只呈現 image，但搜尋仍找的到 h1 內容，不然搜尋引擎會以為你的 h1 是空的

此技巧早期常用於網站 Logo，但現代網頁多半直接使用 <img> 搭配 alt 屬性即可，只有在特定版型需求下才會使用圖片取代文字（Image Replacement）技巧。

補充（路徑、多重背景）

background-image 常見問題

為什麼圖片不顯示？

最常見的原因是路徑錯誤，或容器沒有設定高度（height）。background-image 不會撐開元素高度，務必確保容器有明確的尺寸。

cover 和 contain 怎麼選？

想讓背景填滿整個區塊（例如 Banner）就用 cover；想完整顯示圖片內容（例如 Logo）就用 contain。

background-image 和 img 有什麼差別？

<img> 是內容的一部分，有語意、可被搜尋引擎索引，適合用於產品圖、說明圖等。background-image 屬於裝飾性背景，沒有 alt 屬性，不建議用來呈現重要內容。
