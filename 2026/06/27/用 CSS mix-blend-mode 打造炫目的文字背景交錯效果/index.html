用 CSS mix-blend-mode 打造炫目的文字背景交錯效果

發表於 2026-06-27 分類於 HTML/CSS
深入解析 CSS mix-blend-mode 混合模式原理，透過實際範例手把手教你製作文字與背景交錯的視覺特效，讓你的網頁設計脫穎而出

前言

在現代網頁設計中，視覺上的層次感往往是吸引使用者目光的關鍵。今天要介紹一個純 CSS 就能實現的酷炫效果——文字與背景交錯混合，核心技術是 mix-blend-mode 屬性。這個技巧不需要任何 JavaScript，卻能產生令人驚艷的視覺衝擊。

什麼是 mix-blend-mode？

mix-blend-mode 是 CSS 的混合模式屬性，概念來自 Photoshop 的圖層混合模式。它定義了一個元素的內容如何與其背後的內容進行顏色混合。

常見的混合模式值包括：

值 效果說明
normal 預設，無混合
multiply 正片疊底，顏色相乘變暗
screen 濾色，顏色相加變亮
overlay 覆蓋，加強對比
difference 差異，顏色相減產生反差
exclusion 排除，類似 difference 但對比較低

今天的主角是 difference，它會讓覆蓋的元素顏色與底層顏色相減，當底色是白色（#fff）時，文字顏色會反相，產生天然的「交錯」視覺效果。

基本原理

difference 模式的計算公式是：

以白色文字（#ffffff）為例：

  • 蓋在黑色背景上：|255 - 0| = 255 → 白色，文字清晰可見
  • 蓋在白色背景上：|255 - 255| = 0 → 黑色，文字自動變成黑色

這個特性讓文字天然地在任何背景上保持對比，不需要手動調整顏色。

實作步驟

HTML 結構

結構很簡單：兩個背景色塊 + 一個絕對定位的標題文字。

CSS 樣式

為什麼文字顏色要設白色？

difference 模式下，白色（RGB 255,255,255）會讓計算結果完全反相底色，產生最強的對比效果。若使用其他顏色，效果會不那麼乾淨，但也可以創造不同風格。

進階變化：滾動交錯效果

搭配 CSS 動畫或 scroll，可以讓背景移動而文字固定，強化交錯感。

文字保持 position: fixed 或 sticky，背景在後方滑動，視覺上就像文字穿越兩個世界。

isolation 屬性：控制混合範圍

有時候你不希望混合模式影響到更外層的元素，這時候可以使用 isolation: isolate：

加上這個屬性後，混合效果只會在 .container 內部發生，不會往上影響到 <body> 或其他元素。這在頁面有複雜層疊結構時非常重要。

常見問題

Q：為什麼我的 mix-blend-mode 沒有效果？

確認以下幾點：

  1. 父元素不能設定 isolation: isolate（除非是刻意限制範圍）
  2. 文字元素必須與背景元素有真實的層疊關係，不能在完全獨立的 stacking context 中
  3. 某些 CSS 屬性（如 will-change, transform, opacity < 1）會自動建立新的 stacking context，可能影響混合效果

Q：mix-blend-mode 和 background-blend-mode 有何不同？

  • mix-blend-mode：元素與其下方的所有內容混合（跨元素）
  • background-blend-mode：元素自身的多個背景圖層之間互相混合（單一元素內）

小結

mix-blend-mode: difference 是一個優雅且高效的 CSS 技巧，只需幾行樣式就能實現讓人印象深刻的視覺效果。它的核心概念不難，但組合運用的空間非常大——從靜態的雙色分割版面，到動態滾動、漸層背景，甚至是互動式游標跟隨特效，都能以此為基礎延伸。
