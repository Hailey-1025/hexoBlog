JavaScript classList 完整教學：新增、移除、切換 CSS 類別

在操作網頁互動效果時，經常需要動態地為某個元素加上或移除 CSS 類別，例如切換按鈕的啟用狀態、標示表單輸入錯誤、觸發 CSS 動畫等。這篇文章會完整介紹 classList 這個屬性提供的各種方法，並搭配實際範例說明如何使用。

classList 是什麼？

classList 是 HTML 元素的一個屬性，它提供了操作元素 CSS 類別（class）的方法與屬性，方便進行新增、移除、切換等操作。這比直接操作 className 更直觀、更方便，因為 classList 是針對「個別類別」進行操作，不需要自己處理字串的拆解、拼接、空格或重複等問題。

classList 與 className 的差異

  • className：操作的是整串 class 字串，賦值時會直接覆蓋原本所有的類別。
  • classList：針對個別類別進行操作，不需要自己處理空格、重複等問題。

classList 的屬性：length 與 value

除了上述方法之外，classList 也提供了兩個屬性（不是方法），可以用來讀取目前的類別資訊。

classList.length

回傳元素目前擁有的類別數量。

classList.value

回傳目前所有類別組成的字串，對 HTML 元素而言，內容通常與 className 相同。

常見應用場景

classList 在實務開發中非常常用，以下是幾個常見的實際應用情境：

  • 按鈕啟用狀態：搭配 toggle(className, isActive)，讓按鈕的樣式直接由狀態變數決定。
  • 表單驗證提示：驗證失敗時用 add('error') 加上錯誤樣式，驗證通過後再用 remove('error') 移除。
  • Modal（彈窗）開關：用 toggle('is-open') 切換彈窗的顯示與隱藏。
  • 深色模式（Dark mode）：用 toggle('dark-mode') 切換整個頁面或某個容器的主題樣式。
  • 動畫效果觸發：用 add('fade-in') 加上動畫類別，觸發對應的 CSS 動畫效果。

小結

這篇文章介紹了 classList 的常用方法與屬性：

方法 / 屬性 功能
add() 新增一個或多個類別
remove() 移除一個或多個類別
toggle() 切換類別的存在狀態，可搭配第二個參數讓類別狀態由布林值決定
contains() 檢查是否擁有某個類別
replace() 將某個類別替換為另一個類別，並回傳是否替換成功
length 取得類別數量（屬性，非方法）
value 取得所有類別組成的字串（屬性，非方法）

比起直接操作 className 字串，classList 提供了更語意化、更不容易出錯的方式來管理元素的 CSS 類別，是開發互動效果、表單驗證、Modal、Dark mode 等功能時非常實用的工具。
