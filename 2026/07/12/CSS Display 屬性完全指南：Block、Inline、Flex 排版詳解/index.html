CSS Display 屬性完全指南：Block、Inline、Flex 排版詳解

發表於 2026-07-12 分類於 HTML/CSS
完整解析 CSS display 屬性：從 block、inline、inline-block 到 Flexbox，搭配實用範例與互動遊戲，幫助你快速掌握網頁排版核心技術

CSS Display 屬性完全指南

Display 是 CSS 中最基礎也最重要的屬性之一，它決定了元素在網頁上的呈現方式與排版行為。無論是簡單的文字段落，還是複雜的網頁版面，都離不開對 display 屬性的理解與運用。

本文將深入講解 display: block、display: inline、display: inline-block 以及現代排版利器 display: flex，並提供實用的程式碼範例與學習資源。

Display 屬性基本概念

display 屬性定義了元素的顯示類型，包含：

  • 外部顯示類型：元素本身如何在頁面中排列（如是否換行）
  • 內部顯示類型：元素內部的子元素如何排列（如 flex、grid）

常見的 display 值包括：

  • block - 區塊元素
  • inline - 行內元素
  • inline-block - 行內區塊元素
  • flex - 彈性盒子
  • grid - 網格容器
  • none - 隱藏元素

Display: Block

特性說明

  1. 獨占一行：每個區塊元素都會另起一行，不與其他元素並排
  2. 寬度自適應：預設寬度為父元素的 100%，會盡可能占滿整個版面
  3. 可設定尺寸：可自由設定 width 和 height
  4. 完整盒模型支援：margin、padding、border 在四個方向都完全有效

使用時機

✅ 適合用於：

  • 需要獨立成行的內容區塊
  • 需要設定固定寬高的容器
  • 需要完整控制 margin 和 padding 的元素

Display: Inline

特性說明

  1. 不換行：多個行內元素會在同一行顯示，直到空間不足才會換行
  2. 內容決定寬度：寬度由內容撐開，無法設定 width 和 height
  3. 垂直方向限制：垂直的 margin 和 padding 不會影響排版，視覺上會顯示，但不會推開其他元素

💡 解決方案：如果需要設定寬高但又想保持行內排列，請使用 display: inline-block

常見的 Inline 元素

使用時機

✅ 適合用於：

  • 段落內的文字修飾（強調、連結、標記）
  • 不需要設定寬高的小元素
  • 需要與文字流動排列的內容

Display: Inline-Block

特性說明

inline-block 結合了 inline 和 block 的優點，是實務上最常被使用的混合型態。

  1. 行內排列：元素會並排在同一行顯示（繼承自 inline）
  2. 完整盒模型：可設定 width、height、四方向的 margin 和 padding（繼承自 block）
  3. 垂直對齊：可使用 vertical-align 屬性調整對齊方式
  4. 保留空白：HTML 中的換行和空格會被保留為空隙

使用時機

✅ 適合用於：

  • 需要並排但要設定寬高的元素（按鈕、卡片）
  • 水平導航選單
  • 表單元素的排列
  • 需要 vertical-align 對齊的場景

❌ 不適合用於：

  • 複雜的排版結構（改用 Flexbox 或 Grid）
  • 需要響應式換行的場景（Flexbox 更好）

Display: Flex

Flexbox 是現代網頁排版的主流方式，提供強大且彈性的一維排版能力（一次只處理一個方向：水平或垂直）。

基本概念

當你設定 display: flex 時，該元素會變成：

  • Flex Container（容器）：控制內部元素的排列方式
  • 其直接子元素自動成為 Flex Items（項目）

主軸與交錯軸

  • 主軸（Main Axis）：Flex Items 排列的方向
  • 交錯軸（Cross Axis）：垂直於主軸的方向

Flex Container 屬性

1. flex-direction - 主軸方向

決定 Flex Items 的排列方向。

可用值：

  • row（預設）：水平由左到右
  • row-reverse：水平由右到左
  • column：垂直由上到下
  • column-reverse：垂直由下到上

2. flex-wrap - 換行設定

決定當空間不足時，Flex Items 是否換行。

可用值：

  • nowrap（預設）：不換行，items 會被壓縮
  • wrap：換行，items 保持原始大小
  • wrap-reverse：反向換行

3. justify-content - 主軸對齊

控制 Flex Items 在主軸上的對齊與分布方式。

可用值：

  • flex-start（預設）：靠開始對齊
  • flex-end：靠結束對齊
  • center：置中
  • space-between：兩端對齊，items 之間平均分布
  • space-around：items 周圍有相同空間
  • space-evenly：items 之間和兩端的空間都相等

⚠️ 重要提醒：請使用 flex-start 和 flex-end，而非 start 和 end。後者是較新的語法，會受到文字書寫方向（如阿拉伯文、希伯來文的右到左）影響，可能在多語系網站產生問題。

4. align-items - 交錯軸對齊

控制 Flex Items 在交錯軸上的對齊方式。

可用值：

  • stretch（預設）：拉伸填滿容器高度
  • flex-start：靠開始對齊
  • flex-end：靠結束對齊
  • center：置中
  • baseline：基線對齊

5. gap - 間距設定

設定 Flex Items 之間的間距，比使用 margin 更簡潔。

可用值：

  • 單一數值：gap: 20px - 行列間距相同
  • 兩個數值：gap: 20px 10px - 列間距 20px，行間距 10px
  • 分別設定：row-gap: 20px 和 column-gap: 10px

Flex Items 屬性（設定在子元素）

1. align-self - 個別對齊

覆寫父元素的 align-items，為單一 item 設定不同的對齊方式。

可用值：與 align-items 相同（flex-start、flex-end、center、stretch、baseline）

其他常用 Display 值

display: none

完全隱藏元素，不佔據任何空間。

與 visibility: hidden 的差異：

  • display: none - 元素消失，不佔空間
  • visibility: hidden - 元素隱藏，仍佔空間（像隱形人）

display: grid

二維網格排版系統，比 Flexbox 更適合處理複雜的行列佈局。

💡 Grid 值得另外撰寫專文深入探討，這裡僅作簡介。

總結

快速選擇指南

什麼時候用 Block？

  • 需要獨立成行的大區塊
  • 需要完整控制四個方向的 margin 和 padding
  • 例如：文章段落、容器、區域劃分

什麼時候用 Inline？

  • 需要在文字段落中嵌入的小元素
  • 不需要設定寬高
  • 例如：連結、強調文字、標記

什麼時候用 Inline-Block？

  • 需要並排但要設定寬高
  • 簡單的水平排列
  • 例如：按鈕、導航選單、小卡片

什麼時候用 Flex？

  • 現代排版的首選方案
  • 需要彈性的一維排版（水平或垂直）
  • 需要對齊、分布、間距控制
  • 例如：幾乎所有的排版需求

什麼時候用 Grid？

  • 複雜的二維網格佈局
  • 需要同時控制行和列
  • 例如：相簿、儀表板、複雜版面
