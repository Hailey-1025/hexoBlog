JavaScript for…of 完整教學：語法、範例、break 與 forEach 差異

發表於 2026-07-20 分類於 JavaScript
透過一個表格加總的實作範例，說明 for...of 迴圈的語法、運作原理、與傳統 for 迴圈的差異，並補充 break 中斷迴圈的用法與常見 FAQ。

前言

for...of 是 JavaScript 常用的迴圈語法之一，可以用來依序走訪可迭代物件（Iterable），例如陣列、字串、NodeList 或 HTMLCollection。在操作 DOM 時，也經常會搭配它來走訪一群元素。這篇文章會透過一個簡單的「表格加總」範例，帶你了解 for...of 的語法與使用方式，並比較它跟傳統 for 迴圈的差異。

基本語法

在拆解範例之前，先看 for...of 最基本的寫法：

  • 變數：用來接住當前迭代到的元素，通常會使用 const 宣告；如果需要重新賦值，再使用 let。
  • of：關鍵字，表示後面接的是「要迭代的對象」。
  • 可迭代物件（Iterable）：常見的有陣列、字串、Map、Set，以及類陣列物件如 NodeList、HTMLCollection。

有了這個基本結構，再回頭看範例中的寫法就會清楚很多。

拆解 for (const cell of cells)

1. cells 是什麼？

cells 是透過 data.getElementsByTagName('td') 取得的 HTMLCollection，是一種「類陣列物件」，裡面裝著表格中所有的 <td> 元素。在現代瀏覽器中，HTMLCollection 與 NodeList 都可以搭配 for...of 使用。

2. const cell of cells 的意義

  • cell：區域變數，代表當前迭代到的元素（也就是某一個 <td>）。
  • of：關鍵字，表示接下來要迭代的對象是 cells。

每次迴圈執行時，for...of 會自動依序取出 cells 中的下一個元素，指派給 cell。

為什麼選擇 for...of？

  • 語意清楚：直接針對「每一個元素」操作，不必自己管理索引。
  • 適合類陣列物件：像 HTMLCollection、NodeList 這類物件，用 for...of 走訪起來特別自然。

break 的使用方式

for...of 跟 forEach() 差在哪？

forEach() 是 Array 提供的方法，而 for...of 是 JavaScript 的迴圈語法。兩者都可以用來走訪陣列，但 for...of 還能用於其他可迭代物件（如字串、Map、Set、NodeList 等），且支援 break 中斷迴圈。

總結

  • for...of 是用來迭代「可迭代物件」的語法，語意清楚、易讀性高，特別適合操作 HTMLCollection、NodeList 這類 DOM 集合。
  • 若需要索引值，可改用傳統 for 迴圈，或搭配 entries()。
  • break 可以立即中斷迴圈，不論是 for 或 for...of 都能使用，適合「找到就停」的情境。
  • 如果只是需要依序取得每個元素，通常會優先選擇 for...of；若需要索引值，再考慮使用傳統 for 迴圈。
