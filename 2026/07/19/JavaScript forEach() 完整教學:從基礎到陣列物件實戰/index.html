JavaScript forEach() 完整教學：從基礎到陣列物件實戰

發表於 2026-07-19 分類於 JavaScript
JavaScript forEach() 完整教學，從基礎語法、三個參數、累加、篩選、陣列物件到 Open Data 實戰範例，帶你快速學會 forEach() 的使用方式與常見應用。

前言

學 JavaScript 時，幾乎一定會接觸到 forEach()。

不論是計算總和、篩選資料、處理 API 回傳的陣列，甚至整理 Open Data，都很常看到它的身影。這篇文章會透過一步一步的實戰範例，帶你了解 forEach() 的使用方式，以及它適合解決哪些問題。

forEach() 基礎觀念

forEach() 可以把陣列中的每一筆資料依序拿出來，讓我們對每一筆資料執行相同的操作。在開始寫程式碼之前，先掌握幾個重要觀念：

  • forEach() 最常見於陣列，必須是支援 forEach() 方法的資料型態才能使用，像一般物件 (Object) 就無法直接呼叫。
  • 操作陣列時，通常會透過 陣列.forEach() 的方式呼叫，並傳入一個函式作為參數。
  • 在 forEach() 裡使用 return，只會結束目前這一次回呼函式，並不會中止整個 forEach()。很多人會誤以為 return 可以像 break 一樣提前結束迴圈，實際上並不行。
  • 函式會被執行的次數，取決於陣列裡有幾筆資料。forEach() 會自動把每一筆資料代入函式的參數中。

基本語法範例

forEach() 的回呼函式最多可以接收三個參數：

  1. item：目前這筆資料的值
  2. index：目前這筆資料的索引位置
  3. array：原本的陣列本身

FAQ

什麼情況不適合使用 forEach()？

forEach() 適合用來「走訪並執行動作」，但並不是所有陣列處理情境都適合它。以下是幾種常見的替代選擇：

  • 需要回傳新陣列 → 使用 map()
  • 需要篩選資料 → 使用 filter()
  • 需要把陣列累積成單一結果（如總和、最大值）→ 使用 reduce()
  • 需要提前結束迴圈 → 使用 for...of 或一般的 for 迴圈

理解 forEach() 的限制，才能在對的情境選擇對的方法，寫出更精簡的程式碼。

forEach 可以 break 嗎？

不行。forEach() 沒有中途停止的機制，若需要中途中止迴圈，可以改用 for...of 或一般的 for 迴圈。

forEach 有回傳值嗎？

沒有。forEach() 的回傳值永遠是 undefined，如果需要回傳新陣列，請改用 map()。

forEach 可以搭配 async/await 嗎？

技術上可以，但不建議。因為 forEach() 不會等待每一次回呼函式裡的非同步工作完成就繼續下一輪，因此即使在回呼函式中使用 await，外層程式也不會等待所有非同步工作完成。如果需要「依序」處理非同步任務，通常會改用 for...of 搭配 await。

總結

forEach() 雖然語法簡單，但透過不同的練習組合（累加、篩選、讀取物件、分類整合），可以應付大部分的陣列資料處理情境。整理這幾個常見場景：

情境 用法重點
基礎走訪 熟悉 item、index、array 三個參數，且皆可省略
數字累加 搭配外部變數做加總
條件篩選 搭配 if 判斷，篩選並收集到新陣列（進階可改用 filter()）
讀取物件屬性 用 item.屬性名稱 取值
分類整合 用物件搭配 push() 把資料分類存放

熟悉這些基本組合之後，面對其他陣列方法（如 map()、filter()、reduce()）時，也會更容易上手，因為底層的走訪邏輯是相通的。
